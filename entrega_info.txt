5. RESUMO TÉCNICO DA ARQUITETURA
--------------------------------------------------------------------------------
- Backend: Java 21 LTS, Spring Boot 3.4.3, Spring Data JPA, Spring Security, Flyway, JJWT.
- Banco de Dados: PostgreSQL (Produção/Dev) / H2 modo PostgreSQL (Testes e Dev Local).
- Frontend: React 19, TypeScript, Vite, Axios, React Router, Design System Dark Theme.
- Simulador IoT: Python 3.12, Requests, Dotenv com cenários climáticos controlados.
- Segurança: RBAC (ROLE_ADMIN e ROLE_CIDADAO), JWT stateless, proteção de telemetria
  via cabeçalho X-Sensor-API-Key obrigatório.
